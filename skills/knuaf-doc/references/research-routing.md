# 논문 자료조사 경로

이 문서는 **누구에게 맡기는가**를 정한다.
**어느 사이트부터 여는가**는 [research-sources.md](research-sources.md)를 따른다.
위임 프롬프트에는 관련 범위만 함께 넣는다. 특용·약용작물·생허브 가격은 [price-research-routes.md](price-research-routes.md)의 목적별 경로와 작업 계약을 우선 참조한다. 현재 모델 배정은 [model-routing.md](model-routing.md)가 정본이다.

## 0. 사용자 지정 대상 우선

인터뷰 Q7에서 사용자가 지정한 대상이 있으면 **조사보다 먼저 그것을 다룬다.**
지정이 있는데 조사로 찾은 다른 사례를 채택하면 사용자의 의도를 뒤집는 것이다.

| 항목 | 지정이 있을 때 | 지정이 없을 때 |
|---|---|---|
| 모델농장 | 그 농장을 조사 대상으로 고정 | 유사 사례 2~3곳 조사 후 **확인받고** 확정 |
| 참고 졸업논문 | 해당 논문을 열어 논증 구조 추출 | 학과 참고본에서 유사 작목 탐색 |
| 농법·기술 | 그 방식으로 조사 범위 한정 | 작목 표준 재배법으로 조사 |
| 판로·거래처 | 그 채널 단가·조건 확인 | 판로 후보별 가격 성격을 분리 조사하고, 미확인 농가수취단가를 소매가로 대체하지 않음 |

사용자가 직접 아는 정보(견학·실습·상담)는 공개 자료로 확인되지 않아도 배제하지 않는다.
`kind:interview` / `verified:user-stated`로 원장에 남기고 출처를 명시한다.
다만 **재무 입력값으로 쓸 때는 시세 조사와 교차 확인**한다.

지정 대상을 조사한 결과가 계획과 맞지 않으면(예: 모델농장 규모가 과도하게 큼)
임의로 교체하지 말고 사실을 보고한 뒤 사용자 판단을 받는다.

## 1. 로컬 자료 우선

- 1차 탐색 경로: `00_config.md`의 `source_dir` (사용자 농업자료 폴더)
- 설정되지 않았으면 이 단계를 건너뛰고 외부 조사로 간다.
- 사용자가 지정한 자료 폴더(Obsidian 보관함 등)는 **읽기 전용**으로 다룬다.
- 관련 노트를 실제로 열고 노트 경로, 원출처, 기준연도, 적용 작목·지역을 확인한다. 제목이나 검색 결과만 보고 내용을 단정하지 않는다.
- 노트에 첨부된 원문이나 출처 링크가 있으면 노트 요약보다 원문을 우선한다.
- 가격·통계·법령·정책·시장전망처럼 변하는 정보는 로컬에 있어도 최신 1차 출처로 다시 확인한다.

## 2. 조사 위임 — 역할 배치

조사는 주 모델이 직접 하지 않고 **역할에 맞는 하위 모델에 나눠 맡긴다.**
토큰을 아끼고, 여러 조사를 동시에 돌릴 수 있다.

### 역할 4개

| 레인 | 하는 일 | 필요한 능력 |
|---|---|---|
| **A. 웹 조사** | 통계·시세·정책·지역자료 수집 | 웹 접근, 속도 |
| **B. 문헌 조사** | 학술논문 검색·서지 확보 | 학술DB 접근, 정확성 |
| **C. 계산·구조** | 재무 역산, 엑셀 조립, 수치 검산 | 추론력 |
| **D. 작문** | 절 초안 작성 | 한국어 표현력 |

**정본 통합과 기계 판정 반영은 주 모델이 수행한다.** 초안 작성과 독립 내용검토 배정은 [model-routing.md](model-routing.md)를 따른다.

### 어떤 모델을 쓰나

배정 정본은 [model-routing.md](model-routing.md)다. 자료 해석·문헌 정리·절 초안·윤문은 Luna xhigh에 자동 위임하고, 계산은 로컬 도구로 검증한다. 위임 불가 시 메인이나 다른 모델로 자동 대체하지 않으며 독립적으로 가능한 작업을 계속한다. 과거 설계에서 사용한 모델은 현재 배정의 근거가 아니다.

### 위임할 때 지키는 것 (모델 무관)

- 요청한 모델·경로를 임의로 바꾸지 않는다. 확인 못 하면 중단하고 보고한다
- 비종량제(무료·정액 구독) 경로임을 확인하지 못하면 호출하지 않는다
- 개인정보·미공개 농장정보·재무표·제출 전 원고는 외부 모델에 보내지 않는다
  검색 질문은 필요한 사실만 남기고 익명화한다
- 핵심 주장은 **두 경로로 독립 확인**한다. 이미 특정된 사실에는 중복 조사하지 않는다

## 3. 검색 결과의 증거 등급

- 외부 모델의 답변은 출처 후보와 검색 단서다. 답변 자체를 논문 근거로 인용하지 않는다.
- 모델이 제시한 URL·문헌명·통계표를 직접 열어 발행기관, 제목, 기준연도, 표·페이지, 원문 내용을 확인한다.
- 가능하면 정부·공공기관·학술지·대학·공식 통계 등 1차 출처를 사용한다.
- 두 모델이 같은 내용을 말해도 원문을 확인하지 못하면 `미확인`으로 남긴다.
- 최종 기록에는 `주장 | 확인한 원출처 | 기준연도 | 페이지·표·URL | 로컬/웹조사/위임 중 발견 경로`를 남긴다.

## 4. 웹검색·브라우저

조사에는 **원문을 직접 여는 수단**이 필요하다. 요약만으로는 인용 근거가 안 된다.

### 수단 우선순위

| 순위 | 수단 | 쓸 때 |
|---|---|---|
| 1 | 브라우저 자동화 도구 | 로그인 세션·다운로드·화면 확인이 필요할 때 |
| 2 | 웹 검색 도구 | 출처 후보를 찾을 때 |
| 3 | 하위 모델 위임 | 위 둘이 없거나 조사량이 많을 때 |

환경에 있는 것을 쓴다. **특정 도구를 요구하지 않는다.**

### 어느 수단을 쓰든 지키는 것

- **요약을 인용 근거로 쓰지 않는다.** 실제 원문 페이지를 열어
  발행기관·자료명·기준연도·표·페이지·URL을 확인해 기록한다
- 추측한 URL이나 요소 식별자를 쓰지 않는다. 페이지를 열어 확인한다
- 로그인이 필요한 자료는 접근 가능 여부를 먼저 확인하고,
  불가하면 대체 출처를 찾거나 `확인 불가`로 남긴다
- 링크는 내용이 바뀌거나 사라진다. 받는 즉시 스냅샷을 저장한다(source-intake.md 2항)

### 설계 세션에서 쓴 수단 (참고)

Aside CLI로 로그인 탭을 이어받아 원문을 확인했다.
**배포본에서 이 도구를 요구하지 않는다.**
