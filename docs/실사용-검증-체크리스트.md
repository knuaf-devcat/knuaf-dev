# 실사용 검증 체크리스트 (사람이 직접 확인하는 항목)

자동 테스트(`pytest`, `pnpm test:e2e`)가 못 보는 것만 모았다.
**항목을 확인하면 그 줄에 날짜와 결과를 적고 `[x]`로 바꾼다.** 확인 기록은 체크박스에 남기고,
여러 항목에 걸친 실행 결과는 맨 아래 「실행 기록」에 날짜별로 덧붙인다.

## 실제 Office (macOS)

- [ ] `gg_office.py excel <빈 사본.xlsx> --out-dir <새 폴더>` — 처음 실행 시 macOS 자동화 권한 창이 뜨면 90초 안에 허용. PDF가 생기고 `visible_worksheets`와 PDF 페이지 수가 맞는가.
- [ ] 14시트 학교 양식에 `--spec`(17시트 레거시 검사)을 쓰지 않았는가. 앱의 Office 렌더는 `--spec` 없이 호출한다.
- [ ] `gg.py paper` → `build_docx.py` → `gg_office.py word` — Word가 목차 필드를 갱신하고 PDF를 내는가. 본문 글꼴이 신명조인가.
- [ ] 변환 뒤 원본 파일의 sha256이 그대로인가.
- [ ] Office 작업영역(`~/Library/Group Containers/UBF8T346G9.Office/knuaf-doc/`)이 커지면 문제 해결 화면 대신 `gg_office.py jobs` / `clean --job` 으로 정리한다(앱 UI는 목록만).

## AI 도우미 (내 논문 화면 — 사람이 확인)

- [ ] Codex 채팅 첫 인터뷰: 내 논문 → "Codex (채팅)" → **ChatGPT 로그인**(브라우저 로그인) 후 연결됨 표시가 뜨는가. 질문에 채팅으로 답하면 도우미가 인터뷰를 시작하고 `<프로젝트>/.agents/skills/knuaf-doc` 규칙집을 읽는가.
- [ ] Claude 터미널 첫 인터뷰: "Claude (터미널)" 탭 → 앱 창 안 터미널에 Claude Code가 뜨는가(처음이면 터미널 안에서 로그인). `<프로젝트>/.claude/skills/knuaf-doc` 규칙집을 읽고 인터뷰를 시작하는가. 도우미가 `python3 scripts/gg.py …`를 실행할 때 프로젝트 `.venv`의 3.12가 잡히는가(터미널에서 `which python3`).
- [ ] Claude 터미널 종료 후 **이어서 하기**가 `claude --continue`로 이전 대화를 복원하는가.
- [ ] 터미널에서 한글(IME)로 답변이 정상 입력되는가(자모 분리·중복 입력 없이).
- [ ] 도우미가 저장한 뒤 앱 대시보드를 새로고침(⌘R)하면 개정 번호가 오르는가.
- [ ] Codex/Claude가 없는 Mac에서 내 논문을 열면 "설치가 필요해요" 안내와 설치 안내 열기가 나오는가.
- [ ] Codex 답변 도중(또는 터미널 출력 직후) 대시보드에서 저장·검사 버튼을 누르면 "AI 도우미가 작업 중이에요"(agent_busy)로 거절되는가. 잠시 뒤 다시 누르면 정상 실행되는가.
- [ ] 앱이 저장·검사 작업 중일 때 Codex 채팅 전송이 "앱이 저장·검사 작업 중이에요"로 거절되는가.
- [ ] 채팅 전송 중 앱을 강제 종료한 뒤 재실행하면 "앱이 작업 도중 종료됐어요"와 함께 마지막 답변이 "전송 여부 불확실"(uncertain)로 표시되고, 상태가 파일(`<프로젝트>/.knuaf-gui/chat-codex.json`)에도 그대로 기록되는가. **다시 보내기**로 재전송되는가.
- [ ] 설정 → 앱 밖 터미널로 AI 도우미 열기를 누르면 예전 방식대로 macOS Terminal 창이 열리는가.

## 첫 실행·보안

- [ ] 미서명 dmg에서 앱을 옮긴 뒤 첫 실행: 우클릭 → 열기(macOS 14) 또는 설정 → 그래도 열기(macOS 15+)로 열리는가.
- [ ] 제작자 표시가 첫 실행에만 나오는가(설정 → 최근 폴더 지우기와 무관).

## 재질·테마

- [ ] 밝은 사진 배경 위에서 사이드바(vibrancy) 글자가 읽히는가.
- [ ] 다크 모드 전환 시 흰 플래시 없이 배경이 바뀌는가.
- [ ] 시스템 설정 → 손쉬운 사용 → 투명도 줄이기를 켠 뒤 재실행하면 사이드바가 불투명해지는가.
- [ ] 동작 줄이기를 켜면 화면 전환이 페이드만 남는가.

## Windows (기기 필요)

`pnpm typecheck && pnpm build`와 Python 테스트 전체는 CI의 `windows-latest`가 돌린다.
여기 남은 것은 실제 화면·입력이 있어야 확인되는 항목이다.

- [ ] 사이드바가 불투명하고 창 컨트롤(최소화/닫기)이 가려지지 않는가.
- [ ] 한글(Malgun Gothic) 줄 높이가 잘리지 않는가.
- [ ] 문제 해결 → 패키지 준비가 `.venv\Scripts\python.exe`를 만드는가(복사본 인터프리터).

인터뷰 없이 돌린 결과라 사람이 눌러야 하는 두 지점에서 멈췄다.

  150초 안에 아무도 누르지 않아 시간 초과됐다. 사람이 앞에 있을 때 다시 돌린다.
