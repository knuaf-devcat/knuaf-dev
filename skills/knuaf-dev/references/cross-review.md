# 원문 대조 내용검토

작성자와 다른 검토자가 원답변·원문 발췌·적용 학교 규칙·계산 입력/결과·대상 DRAFT를 직접 대조한다. 작성자의 요약만으로 검토하지 않는다. 같은 작성 맥락에서 한 자가점검은 독립검토가 아니다. 미실행이면 보고서 첫 줄에 `독립검토 미실행`을 표시한다.

각 절의 검토 축: 사실성, 적용 타당성, 논증, 실행성, 일관성, 균형성, 표현. 각 축을 충족/보완 필요/판단 불가로 평가하고 원문 위치와 본문 위치를 기록한다. 키워드 존재·분량·규칙 선언만으로 내용을 승인하지 않는다.

독립검토자는 중요한 비교·추세·공간·일정·재무 흐름을 독자가 이해하는 데 시각자료가 필요한지도 함께 본다. 보완 권고를 단지 학교의 명시적 필수사항이 아니라는 이유만으로 작성자가 제외하지 않는다. 근거 부족·중복·가독성 저하 등 구체적 사유를 기록하거나, 내용 충실도에 영향을 주는 권고를 제외하려면 사용자 확인을 받는다. 그림 수 자체는 통과 기준이 아니다.

필수 기록: id, review_kind, author_id, reviewer_id, target_refs, input_fingerprint, findings, disposition, status, coverage, path. 지적마다 본문 위치·원문 위치·문제·영향·수정 조건·처리 근거를 남긴다. 검토 보고서 파일 해시도 정본에 묶는다. 원자료 의미 변형, 중요 무출처 수치, 기간 오류, 필수 장 누락은 평균 점수로 상쇄하지 않는다.

`gg.py bundle`로 입력 참조와 fingerprint를 얻고 실제 원문 파일을 읽는다. `apply`로 검토를 등록한다. ID가 다르다는 것만으로 실제 독립성이 증명되는 것은 아니므로 검토자 신원·세션·수행 기록을 별도 확인한다. 같은 작성자 ID는 코어가 거부한다. 변경되거나 손상된 보고서·원문·본문은 현재 검토 근거가 아니다.

지적은 원문으로 재확인해 수용 또는 근거 있는 기각으로 처리한다. 항목당 보완/재검토 기본 2회 이후 미해결이면 보류한다. 기계검사·내용검토·출력검토·교수 승인은 각각 기록한다. 교수 승인 없이 검토본을 만들 수 있지만 승인된 제출본이라고 말하지 않는다.

장별 내용 판정에는 [exemplar-quality.md](exemplar-quality.md)를 사용한다. 실제 DRAFT에서 근거→해석→농장 선택→실행→한계가 연결된 위치를 찾고, 적용 학교 규칙의 필수 내용을 원문과 대조한다. 서술 참고자료의 장 구성·분량·숫자가 공식 요구로 승격되지 않았는지도 확인한다. 설명 충분성은 [narrative-expansion.md](narrative-expansion.md)의 검사 항목으로 사실 판정과 분리해 평가한다. 불확실성 표기가 절 도입·표 캡션·검토 부록에 정리됐는지도 본다.

재무 검토는 실제 사용한 제출 양식 사본과 본문을 대조한다. 별도 계산 파일이 맞아도 17시트 사본의 예시 가격·연도·입력값이 남아 있으면 전체 흐름을 승인하지 않는다. 원천 수량의 단위, 총 생산량과 판매가능량, 판로 비중 합계, 가격의 수취 단계, 원/천원 변환, 이자·상환·잔존가치와 실제 적용 산식을 확인한다. 변경 시험에서는 이전 검토·출력의 무효화와 새 개정 산출물의 재검산까지 확인한다.

개발 시험은 명시적으로 표시된 가상 학생·시험 근거를 사용할 수 있다. 이 경우 시험이 증명한 기능과 실제 학생·가격·교수 검증을 분리해 기록한다. 실제 학생 자료 부재를 개발 구현의 중단 사유로 만들지 않는다.

지침 검토자는 [guideline-tracking.md](guideline-tracking.md)의 전체 항목 목록과 실제 원문을 먼저 대조한 뒤, 검토한 항목 ID를 `coverage.guidelines`에 기록한다. 미검토 항목을 전량 coverage에 넣지 않는다. 시각 항목은 실제 렌더와 출력 해시까지 확인한다.


제공 학교 양식의 빨간 입력 시트와 노란색·초록색 자동계산 시트를 구분해 [excel-template.md](excel-template.md)의 역할을 검토한다. 빨간 입력 셀의 숫자 상수나 제출 양식 밖의 별도 투자분석 계산 근거를 결함으로 보지 않는다. 입력값의 출처·산정, 자동 수식의 보존·연도 참조, 재계산 결과와 본문 일치를 검사한다. 실제 계약·대출 실행이 없는 계획서라는 이유만으로 제출 검토를 막지 않으며, 계획상 타당성 판단과 실제 실적 주장을 구분한다.

## 서술 구성과 윤문 검토

사용자 결정에 의존하는 프로필·사업계획 공백이 작성 중 드러났다면 추가 인터뷰 또는 기존 답변 재사용의 근거를 확인한다. 작성자의 대안·무응답을 사용자 확정값으로 승격하지 않았는지, 반대로 실행 증빙 부재만으로 확정 계획을 미정으로 되돌리지 않았는지 구분한다.

확정된 행정구역 주소는 상세 지번이 없어도 사업지 서술로 인정한다. 지번 부재 자체를 차단하지 않되, 별도의 명시적 학교·교수 요구와 특정 필지의 실측·권리·가격을 주장하는 문장의 근거는 구분해 확인한다. 대표 필지의 공시지가를 비교 근거로 사용한 경우 실제 사업 필지의 매입가로 오인시키지 않았는지 검토한다.

[narrative-expansion.md](narrative-expansion.md)의 핵심 프로필 및 작문 허용 범위를 작성자와 동일하게 적용한다. 원문에 같은 문장이 없다는 이유만으로 선택 동기·이름의 의미·경영철학·포부를 삭제하지 않는다. 검토 대상은 프로필과의 모순, 만들어낸 과거 사건·실제 계약·성과, 근거 없는 외부 사실, 임의의 사업 변경이다. 그 밖의 서술 구성은 논리·구체성·화자의 자연스러움으로 평가한다. 학생을 제3자로 소개하는 문체와 내용 대신 문서 관리 절차를 설명하는 문단은 보완한다.

[korean-polishing.md](korean-polishing.md)에 따라 확장 초안과 윤문본을 대조한다. 윤문의 의미 보존 규칙을 앞선 작문 단계로 소급하지 않는다. 조건부 전망을 확정 사실로 바꾸거나, 윤문을 이유로 선택 동기를 다시 삭제하지 않았는지 확인한다.
