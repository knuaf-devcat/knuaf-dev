# im-not-ai 한글 윤문 연결

내용 확장과 사실·수치 대조 뒤, 출력 전에는 `epoko77-ai/im-not-ai`의 `humanize-korean`에서 문장 연결·어휘·리듬을 자연스럽게 다듬는 원칙만 차용한다. 설치된 스킬의 SKILL.md와 룰북을 읽되, 논문 화자·격식·의미 보존은 이 프로젝트 계약을 우선한다. 모델은 사용자가 허용한 경로를 유지하며 플러그인 때문에 변경하지 않는다.

[사용자 결정 2026-09-09] 논문 본문은 ‘입니다·합니다·하고자 합니다’와 같은
격식 있는 어투로 작성한다. ‘있어요·해요’ 등의 대화체로 낮추지 않는다.
자연스러움은 구어체 전환이 아니라 문장 간 논리 연결과 불필요한 반복의
정리로 확보한다. 스킬의 자체 등급이나 변경률을 맞추려고 문체를 바꾸지 않는다.
인터뷰 원답변에 구어체가 있더라도 원답변은 보존하고 작성 본문만 이 기준을 따른다.

## 설치와 읽기

현재 런타임의 스킬 목록에서 `humanize-korean`을 찾아 경로를 해석한다. Codex 기본 위치는 `~/.codex/skills/humanize-korean/SKILL.md`이며 심링크도 유효하다. SKILL.md와 참조 룰북이 읽히면 중복 설치하지 않는다. 미설치라면 https://github.com/epoko77-ai/im-not-ai 의 공식 설치 방법을 확인해 준비하고, 준비 실패 시 사실·작문 작업은 보존하되 해당 윤문 적용은 미완료로 기록한다. 폴더 이름만으로 적용을 완료 처리하지 않는다. 설치 버전의 길이 제한·검증 절차를 따른다.

## 두 단계의 입력을 분리

1. **내용 작문**: 인터뷰 핵심 프로필과 자료를 바탕으로 이유·철학·포부·실행 설명을 구성한다. 이 단계에는 윤문의 의미 불변·변경률 제한을 적용하지 않는다.
2. **문체 윤문**: 완성한 확장 초안을 입력 원문으로 삼아 번역투, 기계적 병렬, 반복 접속사, 과도한 피동과 균일한 리듬을 다듬는다. 이때 사실·주장·수치·이름·인용·조건과 1인칭 화자는 보존한다. 윤문 변경률은 확장 초안과 윤문본 사이에서만 측정한다.

학교 문어체와 사용자 지정 화자를 유지한다. ‘할 수 있다’를 기계적으로 단언형으로 고쳐 수익·성장·효능을 보장하지 않는다. 의미를 바꾸는 내용 보완은 작문 단계로 돌려 처리하고 새 입력을 남긴다. 학교 필수 제목·표·인용은 장르 규칙을 우선한다.

긴 원고는 설치 버전이 지원하는 길이에 맞게 절·문단 단위로 나누고 빠진 구간 없이 처리한다. 위임 작업자는 실제 스킬 지침과 관련 룰북을 받아야 한다. 원문·윤문본·적용한 룰 ID와 변경 내역·검증 결과는 작업 폴더에 남긴다. 도구·모델·룰 ID·진단·변경률 요약 및 플러그인의 등급·HTML 요약은 별도 검토 기록으로 보존하고, 최종 논문 및 학생 DRAFT에는 윤문된 본문만 넣는다.

설치된 윤문 스킬이 변경률 검사기를 제공하면 해당 스킬 경로에서 실제 도구를 확인한 뒤 확장 초안과 윤문본을 대조하고 실행 경로·종료 코드·결과를 기록한다. knuaf-doc가 이 외부 검사기를 포함한다고 가정하지 않는다. 검사기가 없으면 그 사실을 기록하고 원문·결과 해시와 의미 대조를 남긴다. 모델이 스스로 추정한 변경률로 통과를 선언하지 않는다.

## 의미 단위 대조와 병합

윤문 전에 입력을 순서가 있는 chunk ID로 나누고 각 원문 해시를 기록한다.
결과에도 같은 ID·순서와 결과 해시를 붙인다. 누락·중복·순서 변경이 있으면
먼저 그 구간을 복구한다. 이 목록은 실행 증거이며 새 제품 상태 정본이 아니다.

별도 검토자는 모든 chunk의 수치·단위·조건·가능성·부정·주체·출처 귀속을
원문과 대조한다. `할 수 있다 → 한다`, `기록에 따르면` 삭제,
`계산상 예상 → 확정 수익`, `아직 계약하지 않았다 → 계약했다`는
뜻을 바꾸는 부정 사례다. 해당 표현이 일반 윤문 룰의 대상이어도
논문 장르의 사실·계획·조건 보존 계약이 우선한다.
검토용 가정과 계산 산출근거는 학생에게 필요한 설명이며 일괄 삭제하지 않는다.

검사기 종료 코드 0이나 변경률은 의미 보존 판정이 아니다.
실패한 chunk만 원문 근거로 수리하고 새 해시를 남긴 뒤,
병합본의 연결·중복·지시어와 원문 순서를 다시 대조한다.
