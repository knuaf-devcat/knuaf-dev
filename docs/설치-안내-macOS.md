### 처음 열 때 "열 수 없습니다"가 뜨면

이 앱은 아직 Apple 개발자 서명을 받지 않았습니다. 그래서 macOS가 처음 한 번
막습니다. 앱에 문제가 있다는 뜻은 아니고, **누가 만들었는지 Apple이 보증하지
않았다**는 뜻입니다.

한 번만 아래대로 하면 다음부터는 그냥 열립니다.

1. 내려받은 `.dmg`를 열고 앱을 **응용 프로그램** 폴더로 끌어다 놓습니다.
2. 앱을 실행합니다. 열리지 않고 경고가 뜹니다. **여기서 한 번 실행을 시도해야**
   다음 단계의 버튼이 나타납니다.
3. 이 경고 창의 버튼은 **[휴지통으로 이동]**과 **[완료]** 둘입니다.
   **"완료"를 눌러 창을 닫으세요.** 기본 버튼이 "휴지통으로 이동"이라,
   그냥 Return을 누르면 방금 설치한 앱이 휴지통으로 갑니다.
4. **시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
5. 아래로 내리면 맨 아래 보안 항목에 **"Mac을 보호하기 위해
   'KNUAF-Dev · 창업논문 작성 도우미'을(를) 차단했습니다."** 가 보입니다. 그 아래 **"그래도 열기"** 버튼을
   누릅니다.
6. 확인 창이 한 번 더 뜹니다. 버튼은 **[휴지통으로 이동]**, **[그래도 열기]**,
   **[완료]** 셋입니다. 여기서도 기본 버튼은 "휴지통으로 이동"입니다.
   Return을 누르지 말고 **"그래도 열기"** 를 누르세요.
7. 암호를 입력합니다.
8. 앱을 다시 실행합니다. 이제 열립니다.

> 예전 macOS에서 쓰던 "앱을 마우스 오른쪽 버튼으로 눌러 열기"는 최근 버전에서는
> 더 이상 통하지 않습니다. 위의 시스템 설정 경로를 쓰세요.

내려받은 파일이 중간에 손상되지 않았는지 확인하려면, 릴리스에 함께 올라온
`SHA256SUMS-macos.txt`와 대조하면 됩니다. 터미널에서:

    shasum -a 256 ~/Downloads/knuaf-dev-*.dmg

### AI 연결 시 주의사항

첫 화면에서 ChatGPT나 Claude 계정을 연결할 때, **Claude·ChatGPT의 추가 사용(크레딧 충전)은 켜지 마세요.** 종량제로 추가 요금이 나갈 수 있으니 기본 정액 요금제나 기본 상태로만 사용하세요.

### 앱과 규칙집 업데이트

- **앱 새 판 업데이트**: 새 앱 판이 나오면 창 맨 위 제목줄 오른쪽의 **"업데이트"** 단추를 누르고 **"내려받기 페이지 열기"**를 눌러 GitHub에서 새 `.dmg` 파일을 받아 설치합니다. 맥은 보안 인증 절차가 진행 중이어서, 새 판을 처음 열 때도 위의 시스템 설정 **"그래도 열기"** 안내대로 한 번 열어 주면 됩니다.
- **규칙집 업데이트**: 설정 화면의 **앱 정보 → 업데이트** 칸에서 새 규칙집을 확인하고 업데이트하거나 이전 규칙집으로 되돌릴 수 있습니다. 서명이 확인된 안전한 규칙집만 받아 적용하며, 도우미의 답변이나 진행 중인 작업이 끝나기를 잠시 기다립니다. 만약 업데이트하지 못했다는 안내가 나오면 작업이 끝난 뒤 **"다시 시도"**를 누르세요. 업데이트한 규칙집을 쓰고 있을 때는 **"이전 규칙집으로"** 단추를 눌러 보관된 이전 판(또는 앱에 원래 들어 있던 판)으로 되돌릴 수 있습니다. 업데이트에 실패하면 이전 판이나 앱에 원래 들어 있던 판으로 자동 복구됩니다.
- **업데이트를 확인할 수 없을 때**: 인터넷이 끊겨 업데이트를 확인할 수 없을 때도 지금 앱과 규칙집은 그대로 쓸 수 있습니다.
- **업데이트 뒤 앱이 열리지 않을 때**: GitHub 릴리스에서 최신 설치 파일을 다시 받아 응용 프로그램 폴더로 복사해 설치하세요. 기존 논문 자료는 그대로 유지됩니다.
