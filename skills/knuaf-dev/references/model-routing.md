# 위임 — 역할·모델·기록

**위임하기 직전에 읽는다.** 담당을 따로 두지 않는 세션에서는 이 문서가 필요 없다.
지켜야 할 선은 SKILL.md 에 이미 있다.

## 역할 배정

사용자가 작업별 모델·effort·경로를 지정했으면 그것이 최우선이다. 비슷한 버전으로
바꾸거나 effort 를 낮추지 않는다. 지정한 모델이 이 호스트에 없으면 호출 실패가 아니라
**배정 불가**이고, 아래 「호스트별 경로」를 적용한 뒤 실효 모델을 기록한다.

모델 지정은 추가 과금·다른 계정·외부 전송에 대한 포괄 승인이 아니다. 요청한 모델과
허용된 경로를 쓸 수 없으면 그 작업만 보류하고 이유를 알린다. 다른 작업은 계속한다.

배정은 모델 이름이 아니라 **역할**로 정의한다.

| 작업 | 역할 |
| --- | --- |
| 파일 목록·해시·PDF 텍스트·XLSX 셀 추출·계산 | 로컬 도구 (대량 추출은 자료 담당에게 맡길 수 있다) |
| 자료 해석·출처 위치 정리·학교 지침 대응 | 자료 담당 — 긴 원문을 읽고 위치를 정확히 짚는다. 높은 추론 설정 |
| 장별 초안·한글 윤문 | 작성 담당 — 같은 품질 계약, 높은 추론 설정 |
| 인터뷰·상충 자료 판단·논리 구성·최종 통합 | 메인 |
| 독립 내용검토 | 그 글을 쓰지 않은 담당. 같은 작성자의 자가점검은 이를 대체하지 않는다 |

## 호스트별 경로

현재 호스트가 주는 하위 에이전트 수단을 먼저 확인하고, 없으면 아래로 내려간다.
필드 이름은 런타임마다 다르므로 실제 제공되는 필드를 확인해 쓴다.

1. **모델·effort 를 지정할 수 있다** — 담당마다 명시한다. 모델을 생략해 메인 모델을
   암묵 상속시키지 않는다. 고정 모델이 요청값을 덮어쓰는 에이전트는 쓰지 않는다.
   독립 맥락을 줄 수 있으면 대화 이력을 상속시키지 않는다.
2. **하위 에이전트는 있으나 모델을 못 고른다** — 역할 분리는 유지한다. 독립 내용검토는
   작성에 참여하지 않은 담당이 맡는 것만으로 의미가 있다. 실효 모델은 관측값으로 기록.
3. **별도 담당을 둘 수 없다** — 메인이 같은 품질 계약으로 수행한다. 이것은 호출 실패가
   아니라 정상 경로다. 다만 "독립 검토"라고 부르지 않고 보고서 첫 줄에 독립검토 미실행을
   표시하며, 실효 모델은 `unverified` 로 남긴다.

지정 미지원·호출 실패·사용량 한도를 만나면 그 위임을 미실행으로 기록한다. 같은 오류를
반복 호출하지 않고, 메인·다른 모델·다른 공급자로 **자동 대체하지 않는다.** 이름만 목록에
있다고 호출 가능하다고 보지 않는다. 모델 변경은 사용자가 명시적으로 허용한 뒤 적용한다.

## 무엇을 전달하고 무엇을 남기는가

- 전달: 출처 ID·경로·해시·페이지/시트 범위, 필요한 지침, 기존 답변, 대상 절, 산출물 경로.
  전체 대화나 전체 자료를 매번 복제하지 않는다. 이미 유효한 발췌는 재사용한다.
- 담당은 **자기가 소유한 파일에만** 저장한다. 같은 파일을 여럿에게 맡기지 않는다.
  `project.json` 반영과 최종 통합은 메인이 직렬로 한다. 메인은 돌아온 근거 위치와 핵심
  숫자를 원문·계산으로 확인한다.
- 작성 위임에는 핵심 프로필, 사용자 작문 요청, 1인칭 문체, 그리고
  [narrative-expansion.md](narrative-expansion.md) 의 작문 허용 범위와 단계 E(시각자료
  판단)를 함께 전달한다. '새 동기 추가 금지' 같은 지시로 선택 이유·포부의 구성을 막지
  않는다. 검토 담당에게는 채택한 그림뿐 아니라 **생략 사유**도 전달한다.
- 윤문 위임에는 [korean-polishing.md](korean-polishing.md) 에 따라 설치된
  `humanize-korean` 지침을 전달한다. 파일을 읽을 수 없는 담당에게는 본문을 실제로
  전달한다 — 스킬 이름만 적고 적용했다고 기록하지 않는다.
- 가격 조사는 [price-research-routes.md](price-research-routes.md) 를 먼저 읽고,
  작목 별칭·상품 형태·원산지/규격/단위·지역·판로·기간·필요한 가격 성격·원답변과 출처
  ID·이미 실패한 경로·결과 저장 위치를 작업 계약으로 전달한다. "시세를 찾아라"만
  던지지 않는다. 모르는 조건은 미확정으로 두고 추정해 채우지 않는다.
- 기록: 작업 ID·담당 ID·요청 모델/effort·입력 위치와 해시·출력 위치·실행 결과를
  `audit/model-routing/` 에 남긴다. 요청값과 실행으로 확인된 값을 구분하고, 관측할 수
  없으면 `unverified`. 이 기록은 감사 증거이지 `project.json` 의 품질 상태가 아니다.
- 학생에게는 "자료를 정리하고 있어" 처럼 진행만 말한다. 서브에이전트 명령이나 설정을
  학생이 입력하게 하지 않는다.

## 재개

이미 실행 중인 담당의 설정이 소급 변경됐다고 가정하지 않는다. 새 세션에서도 같은
작업폴더의 상태·원답변·발췌·미결 질문을 이어받으며, 모델 배정이 바뀌었다는 이유만으로
초기화하거나 재인터뷰하지 않는다.
