# 실행 능력과 검토 독립성

## Codex 자동 위임 — 사용자 결정 2026-09-07

**사용자가 명시한 작업별 모델·effort·허용 경로는 아래 기본 배정보다 우선한다.** 예를 들어 “웹서칭·자료 조사는 gemini3.7 flash, 논문 작성은 luna max”라고 지정하면 해당 범위에 각각 요청값을 적용하고, 지정하지 않은 작업만 기본 배정을 유지한다. 이후 정정한 지시가 이전 배정보다 우선한다. 시작·재개 때 현재 사용자 지정 배정을 작업 기록에서 이어받는다. 사용자 지정 모델명은 실제 지원 모델 ID로 확인하되 유사한 버전으로 바꾸거나 effort를 낮추지 않는다. 이 문서의 Luna xhigh 호출 예시는 사용자 지정이 없을 때의 기본값이다.

모델 지정은 추가 과금·다른 계정·외부 자료 전송·허용되지 않은 호출 경로에 대한 포괄 승인이 아니다. 정확한 요청 모델·effort와 허용된 경로를 사용할 수 없으면 해당 작업을 보류하고 이유를 알린다. 다른 범위의 가능한 작업은 계속한다.

학생에게 모델이나 하위 에이전트 선택을 묻지 않는다. 자료를 받거나 절 작성을 시작하면 다음 배정을 적용한다. 이것은 이 스킬의 실행 기본값이며 학교 지침·출처·검토의 품질 기준을 바꾸지 않는다.

| 작업 | 실행 주체 |
| --- | --- |
| 파일 목록·해시·PDF 텍스트·XLSX 셀 추출·계산 | 로컬 도구. 대량 추출 도구 실행은 자료 담당에게 맡길 수 있다. |
| 자료 해석·출처와 원문 위치 정리·학교 지침 대응 | `gpt-5.6-luna`, `xhigh` |
| 장별 초안·한글 윤문 | `gpt-5.6-luna`, `xhigh` |
| 인터뷰·상충 자료 판단·논리 구성·최종 통합 | 현재 메인 모델 |
| 독립 내용검토 | 대상 작성·수정에 참여하지 않은 별도 에이전트. 기본 `gpt-5.6-luna`, `xhigh`. |

### 실제 호출과 작업 분리

- 현재 Codex가 제공하는 네이티브 하위 에이전트 도구에서 모델·effort 지정 가능 여부를 확인한다. 도구가 `spawn_agent`라면 `model="gpt-5.6-luna"`, `reasoning_effort="xhigh"`를 명시한다. `fork_turns`가 제공되면 `"none"`으로 독립 맥락을 주고 필요한 작업 계약만 전달한다. 다른 런타임은 실제 지원하는 동등한 필드를 사용한다. 모델을 생략해 메인 모델을 상속시키지 않는다. 고정 모델 역할이 요청값을 덮어쓰는 에이전트는 사용하지 않는다.
- 메인은 파일 경로·인덱스·기존 발췌 범위부터 확인하고, 자료 전문 읽기·해석과 장별 작성은 담당에게 맡긴다. 전달할 것은 해당 출처 ID·경로·해시·페이지/시트 범위, 필요한 지침, 기존 답변, 대상 절, 산출물 경로다. 전체 대화·전체 자료를 매번 복제하지 않는다. 기존 유효 발췌를 재사용한다.
- 가격 조사 위임 전 [price-research-routes.md](price-research-routes.md)를 읽는다. 작목/사이트상 별칭, 생물·건조 등 상품 형태, 원산지·규격·단위, 지역·판로·기간, 필요한 가격 성격, 현재 원답변·출처 ID, 이미 조사한 경로/실패 이유, 결과 저장 위치를 짧은 작업 계약으로 전달한다. 모르는 조건은 미확정으로 표시하며 추정해 채우지 않는다. 담당에게 해당 안내의 실제 경로와 우선 조회 경로를 지정한다. “시세를 찾아라”만 전달하거나 전체 대화를 무작정 복제하지 않는다. 작업 계약과 결과는 작업폴더에 보존해 재개 시 같은 맥락을 이어받는다.
- 담당은 발췌와 초안 후보를 소유한 파일에만 저장한다. 여러 담당에게 같은 파일을 맡기지 않는다. `project.json` 반영과 최종 통합은 메인이 직렬로 수행한다. 메인은 반환된 근거 위치와 핵심 숫자를 원문·계산으로 확인하며, 필요한 원문 재열람은 허용한다.
- 호출 시 작업 ID·담당 ID·요청 모델/effort·입력 위치/해시·출력 위치·실행 결과를 작업폴더의 `audit/model-routing/`에 기록한다. 실행 정보로 확인된 모델/effort와 요청값을 구분하며, 관측할 수 없는 실효값은 `unverified`로 남긴다. 이 기록은 감사 증거이며 `project.json`의 품질 상태를 대신하지 않는다.
- 학생에게는 “자료를 정리하고 있어”, “초안을 작성한 뒤 근거를 검토할게”처럼 진행을 설명한다. 서브 에이전트 명령이나 설정을 학생이 입력하게 하지 않는다.

### 사용할 수 없을 때와 재개

현재 적용된 배정(사용자 지정 우선, 미지정 시 Luna xhigh)의 지정 미지원·호출 실패·사용량 한도이면 해당 위임을 미실행으로 기록한다. 동일 오류를 반복 호출하거나 메인·다른 모델·다른 공급자로 자동 대체하지 않는다. 기존 저장, 로컬 검사, 인터뷰 등 독립적으로 가능한 작업은 계속하고 학생에게 막힌 작업과 이유만 간단히 알린다. 모델 변경은 사용자가 명시적으로 허용한 뒤 적용한다. Gemini·Claude 등 다른 공급자의 이름만 목록에 넣어 호출 가능하다고 간주하지 않는다. 외부 호출은 명시적으로 허용된 계정·과금·경로에서만 수행하며 자동 유료 프로브와 대체를 하지 않는다.

기존 세션은 다음 작업 전에 수정된 `SKILL.md`와 이 문서를 다시 읽어 이후 호출부터 적용한다. 이미 실행 중인 담당의 설정이 소급 변경됐다고 가정하지 않는다. 새 세션에서도 같은 작업폴더의 상태·원답변·발췌·미결 질문을 이어받고, 모델 배정 변경만으로 초기화하거나 재인터뷰하지 않는다.

## 실행 능력과 검토 증거

`gg.py doctor <폴더>`는 Python·패키지 탐지와 잠금·임시파일을 보고한다. 설치 탐지는 실행 성공이 아니다. 파일 읽기/쓰기, DOCX 생성, XLSX 생성, 재계산, 원문 추출, 글꼴, 렌더는 각각 작은 로컬 예제로 확인하고 실행 명령·결과·버전을 기록한다.

- 파일·실행 도구가 있으면 공통 코어와 가능한 검사를 실행한다.
- 일부 도구가 없으면 해당 검사만 blocked/not_run으로 기록한다. 학교 필수성은 바꾸지 않는다.
- 채팅만 가능하면 초안·질문·제공 원문 해석을 진행한다. 자동 저장·기계검사·재계산을 수행했다고 말하지 않는다.

채팅 인계에는 원답변 그대로, 사실/목표/가정의 구분, 단위·기간·출처 위치, 현재 초안, 미결 질문 ID·횟수, 미실행 검사를 복사 가능한 형태로 제공한다. 정식 검증 환경에서 재등록·검사하기 전 제출 후보로 승격하지 않는다.

다른 검토자나 별도 작성 맥락 없는 세션을 사용할 수 있으면 원문을 제공해 독립검토한다. 같은 작성자의 자가점검은 이를 대체하지 않는다. 조사·작성의 보완은 실패 원인과 대상 범위를 기록해 제한적으로 수행한다. 항목당 수정/재검토 기본 2회 소진 시 해결된 것으로 처리하지 않는다.


## 작성·검토 위임에 전달할 계약

해당 절에서 설명할 비교·변화·공간·작업 흐름과 기존 원문 도표·데이터 위치도 함께 전달한다. 작성 담당은 [narrative-expansion.md](narrative-expansion.md)의 단계 E에 따라 시각자료의 필요성, 사용할 근거, 제작·삽입 위치를 판단한다. 검토 담당에게는 채택한 그림뿐 아니라 중요한 생략 사유도 전달한다. 학교의 명시적 그림 수 규칙이 없다는 이유만으로 그림 제작을 일괄 금지하거나 내용 충실도 검토에서 제외하지 않는다. 읽기 전용 등 도구 제약으로 제작하지 못한 부분은 메인의 통합 작업으로 남기며, 후보 목록만으로 삽입 완료를 주장하지 않는다.

모델 선택과 별개로 핵심 프로필, 사용자 작문 요청, [narrative-expansion.md](narrative-expansion.md)의 작문 허용 범위, 1인칭 문체를 함께 전달한다. ‘새 동기 추가 금지’나 ‘인터뷰의 문장만 사용’ 같은 지시로 선택 이유·포부의 구성을 막지 않는다. 작문자는 프로필에 맞는 내용을 확장하고 검토자는 같은 허용 범위에서 대조한다. 윤문 위임에는 [korean-polishing.md](korean-polishing.md)에 따라 설치된 `humanize-korean` 지침과 관련 룰북을 전달한다. 파일을 읽을 수 없는 작업자에게는 필요한 본문을 실제로 전달하며, 스킬 이름만 적었다고 적용한 것으로 기록하지 않는다.
